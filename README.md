Runway Dawn — an open-world crime game set at a dawn airport: steal cars, dodge the airport police, and pull off three heists across runways, hangars and the control tower.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests — just static files under `game/`.
